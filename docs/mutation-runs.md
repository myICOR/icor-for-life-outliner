# Mutation runs

Recorded 2026-09-06 for 0.1.0 (keyboard schemes) by `npm run mutate` (`test/mutate.mjs`). Each row breaks one guard in a copy of the source and lists the fixture cases that went red against it. A row with zero red cases fails the run; the release workflow runs this after the gate. Phase 1 recorded 11 mutations over 134 cases; phase 2 added 17 mutations and 124 cases; phase 3 (Flint's first review applied) added one mutation for the node classifier's parsed-non-list rule and five guard fixtures; phase 4 (Flint's second review applied) adds one mutation for the fold marker's placement before a trailing block id and six fold-marker fixtures, and repoints the marker-strip mutation at the rewritten `withoutFoldMarker`; the keyboard-scheme phase adds one mutation on the editor layer (`layer: 'cm'`, built with the cm harness and run against the 11 scheme cases in `test/lib/scheme-cases.mjs` instead of the fixture corpus): a scheme key returning true when the operation passed, which the three passthrough cases catch. Every earlier row still goes red.
