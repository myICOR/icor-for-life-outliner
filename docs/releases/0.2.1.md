# ICOR for Life - Outliner 0.2.1

Ready for ICOR for Life 3.0, whose folders are grouped by ICOR stage and
renumbered, with no work-in-progress folder. The Outliner reads no vault
folder, so nothing about how it works has changed: a note in the source no
longer names a folder the vault does not have, and a test keeps the old
folder names and the old word for a folder out of the plugin.

Needs Obsidian 1.13.0 or newer. Copy `main.js`, `manifest.json` and
`styles.css` into `<vault>/.obsidian/plugins/icor-for-life-outliner/`.
